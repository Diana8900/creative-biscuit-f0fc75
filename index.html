手机端读取 NFC 的使用前提与操作步骤

本工具基于浏览器 Web NFC（NDEFReader）接口实现。先看清前提，否则碰贴片不会有反应。

一、使用前提（缺一不可）

  1. 安卓手机：需 Android 5.0+ 且带 NFC 芯片，浏览器用 Chrome / Edge / Samsung Internet（同为 Chromium 内核）。
    iPhone / iPad 的任何浏览器（含 Chrome、Edge）目前都不支持 Web NFC；iOS 只能在原生 App 里读 NFC。苹果用户请用本工具的「手动记一次」模式。
  2. HTTPS 安全环境：页面必须运行在 https:// 或 localhost 下。用 file:// 直接双击打开，或普通 http:// 局域网地址，NFC 会被浏览器安全策略拦截。
    最简方案：把本文件托管到免费静态空间（GitHub Pages / Netlify / Vercel / Cloudflare Pages），用手机访问其 https 链接即可。
  3. 手机开启 NFC：系统设置里打开 NFC 开关（部分机型在「连接与共享」中）。
  4. 用户手势 + 授权：浏览器规定扫描必须由一次点击触发，且首次使用会弹窗请求 NFC 权限，需点「允许」。

二、操作步骤

  1. 把本文件部署到 HTTPS 地址（见上），用手机浏览器打开。
  2. 点页面上的「开始监听 NFC」（这一步就是必需的「用户手势」），在权限弹窗点允许。
  3. 把手机背面上半部分（NFC 天线通常在摄像头附近）贴近 NTAG 贴片，约 0.5 秒即自动写入一条记录，并弹出成功提示。
  4. 贴片区分使用者：先在「贴片管理」填名字点添加 → 碰一下贴片完成绑定；之后该贴片每次打卡都归到这个名字下。

三、贴片选购与写入

  • 买 NTAG213 / NTAG215 空白不干胶贴片（淘宝约 ¥1–2/张，整卷更便宜），无需预写内容——本工具直接读取贴片硬件 UID 来识别身份。
  • 若你希望贴片里存可读文本（如 user:dad），可用「NFC Tools」等 App 写入一条 Text 记录，本工具会优先用文本内容识别。
  • 同一张贴片 3 秒内重复碰，会被判为误触而忽略，避免重复记。

四、本地测试（无手机 / 无贴片也能跑）

  • 桌面浏览器打开本文件：NFC 不可用时会自动显示提示，可用「手动记一次」体验完整流程，数据同样本地保存。
  • 想在电脑上真读 NFC，需要外接 USB 读卡器 + 原生程序（Web NFC 不认外接读卡器），本工具未覆盖该场景。
  • 临时用手机测本地页面：在本机运行 python -m http.server 后用 ngrok / localtunnel 等把 localhost 映射成 https 链接，再在手机打开。

数据仅保存在本机浏览器（localStorage），不会上传任何服务器。
